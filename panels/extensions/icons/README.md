# Extension icons

Source: GNOME Icon Development Kit, `old/icons.svg`, commit `e5857f6d796a96571a61030db40f35bfb8815a94`.

Upstream: https://gitlab.gnome.org/Teams/Design/icon-development-kit

License: CC0-1.0; upstream license retained in `COPYING.md`.

- `globe-alt2-symbolic.svg`: globe-alt2 path, translated into a 16×16 canvas.
- `monge-extensions-outline-symbolic.svg`: puzzle-piece path, translated into a 16×16 canvas and changed to a rounded 1.5px outline, with quarter-pixel-positioned stroke centres to align one edge of each straight stroke to the pixel grid.
